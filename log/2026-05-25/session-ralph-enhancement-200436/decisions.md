## 关键决策记录

### 1. 每步成功即提交

- **问题**: Ralph 循环每轮迭代完成后没有代码提交，无法提供版本回滚和精确的变更差分
- **决策**: Ralph 子 agent 实现故事后立即 `git commit`；修复 agent 修复后也立即提交
- **理由**: 为下一轮迭代的 agent 提供 `git diff HEAD~1..HEAD`，让全新上下文能客观评估现状；同时提供版本回滚点
- **影响**: Ralph agent 任务新增步骤 4（提交代码变更），主循环新增步骤 4（验证提交 + 获取差分）

### 2. Git 差分替代重新读文件

- **问题**: 全新上下文的 agent 只能通过重新读取文件来理解代码状态，但重构、格式化、删除等变更在读取文件中不可见
- **决策**: 新增"Git 差分驱动上下文"小节，指导 agent 通过 `git diff HEAD~1..HEAD` 获取精确变更
- **理由**: diff 精确显示"之前 vs 之后"，让 agent 立即理解关键变化，避免从头理解整个文件
