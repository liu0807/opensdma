# PRD: 命令行数据搬移工具

## 简介
实现一个命令行数据搬移工具，用户通过命令行参数指定源地址和目标地址，支持同步和异步两种搬移模式。

## 目标
1. 支持通过 CLI 指定源地址和目标地址
2. 支持同步模式：阻塞等待搬移完成并返回结果
3. 支持异步模式：提交后立即返回任务 ID，后台执行，可查询状态

## 用户故事

### US-001: 命令行参数指定地址
作为用户，我可以通过命令行参数 `--src` 和 `--dst` 指定搬移的源地址和目标地址，地址可以是文件或目录路径。

验收标准：
- `--src <path>`：指定源路径
- `--dst <path>`：指定目标路径
- 支持绝对路径和相对路径
- 缺失必选参数时提示错误

### US-002: 同步搬移模式
作为用户，我可以在同步模式下执行数据搬移，命令阻塞等待直到搬移完成，并看到搬移结果。

验收标准：
- 默认模式为同步
- 阻塞等待直到搬移完成
- 输出搬移结果：成功/失败、搬移字节数、耗时
- 支持进度条实时显示搬移进度

### US-003: 异步搬移模式
作为用户，我可以在异步模式下提交搬移任务，立即获得任务 ID，后续通过任务 ID 查询搬移状态和结果。

验收标准：
- `--mode async` 切换为异步模式
- 立即返回任务 ID（格式：task-<uuid>）
- 支持通过 `--status <task-id>` 查询任务状态
- 任务状态包括：pending、running、completed、failed

### US-004: 覆盖策略控制
作为用户，我可以控制是否覆盖已存在的目标文件，避免误覆盖重要数据。

验收标准：
- `--overwrite` 或 `-o`：覆盖已存在的目标文件
- 默认不覆盖，目标已存在时跳过并提示
- 跳过文件计入结果统计

### US-005: 递归搬移目录
作为用户，我可以递归搬移整个目录及其子目录和文件。

验收标准：
- `--recursive` 或 `-r`：递归搬移
- 非递归模式下仅搬移目录自身
- 递归模式下保持目录结构

### US-006: 错误处理与提示
作为用户，当搬移出现异常时，我能收到明确、有意义的错误信息。

验收标准：
- 源地址不存在：提示 "源地址不存在: <path>"
- 目标地址不可写：提示 "目标地址不可写: <path>"
- 权限不足：提示 "权限不足: <path>"
- 磁盘空间不足：提示 "磁盘空间不足"
- 异步任务查询时任务 ID 不存在：提示 "任务不存在: <task-id>"

| FR-3 | 异步搬移模式，返回任务 ID，后台执行 | P0 |

| FR-7 | 递归搬移目录（--recursive/-r） | P1 |

## CLI 接口设计

```
datamover --src <source> --dst <destination> [选项]

选项：
  -m, --mode <sync|async>    搬移模式，默认为 sync
  -o, --overwrite             覆盖已存在的目标文件
  -r, --recursive             递归搬移目录
  -s, --status <task-id>      查询异步任务状态
  -h, --help                  显示帮助信息

示例：
  datamover --src /data/file.txt --dst /backup/file.txt
  datamover --src /data/dir --dst /backup/dir -m async
  datamover --src /data/src --dst /data/dst -o -r
  datamover --status task-a1b2c3d4
```

## 非功能需求

- 搬移大文件（>1GB）时不出现内存溢出
- 异步模式下支持同时运行多个任务
- 错误信息清晰可读，便于用户定位问题
- 命令行响应迅速，参数解析耗时 < 100ms

## 非目标

- 不做跨平台兼容（仅 Linux/Unix）
- 不支持网络传输协议（如 FTP、SCP）
- 不做图形界面

## 成功指标

- 同步模式下文件可正确搬移并返回准确结果
- 异步模式下可提交任务、查询状态、获取最终结果
- 覆盖策略、递归搬移按预期工作
- 异常场景给出有意义的错误提示
- 大文件搬移功能正常，无内存泄漏
