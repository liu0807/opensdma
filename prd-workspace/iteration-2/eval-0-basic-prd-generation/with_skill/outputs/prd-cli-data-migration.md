# PRD: CLI 数据搬移工具

## 简介

提供一个命令行工具，支持用户通过命名参数指定源地址和目标地址，在本地文件系统之间进行数据搬移。工具同时支持同步（阻塞等待完成）和异步（提交后立即返回，通过轮询获取结果）两种模式，满足不同场景下的使用需求。

## 目标

- 支持通过 `--src` 和 `--dst` 命名参数指定源路径和目标路径
- 支持同步模式：阻塞等待，搬移完成后返回结果
- 支持异步模式：提交任务后立即返回任务 ID，支持通过任务 ID 查询搬移状态和结果
- 大文件（>1GB）搬移性能可接受，不出现明显的内存溢出或无响应
- 提供清晰的使用帮助和错误提示信息

## 用户故事

### US-001: 命令行参数解析与校验
**描述：** 作为用户，我可以通过 `--src` 和 `--dst` 命名参数指定源地址和目标地址，并通过 `--mode` 选择同步或异步模式，以便灵活配置搬移任务。

**验收标准：**
- [ ] `--src <path>` 指定源文件/目录路径，缺失时提示错误
- [ ] `--dst <path>` 指定目标路径，缺失时提示错误
- [ ] `--mode sync|async` 指定搬移模式，默认 sync
- [ ] `--help` 显示完整的参数说明和使用示例
- [ ] 源路径不存在时，给出明确的错误提示并退出
- [ ] 目标路径不可写时，给出明确的错误提示并退出
- [ ] Typecheck 通过

### US-002: 同步模式数据搬移
**描述：** 作为用户，我选择同步模式时，工具阻塞等待搬移完成，并在终端实时显示搬移进度和最终结果。

**验收标准：**
- [ ] 同步模式下，搬移完成后打印成功/失败信息
- [ ] 同步模式下，进度信息（已搬移大小/总大小、速度）实时更新
- [ ] 同步模式下，搬移过程中按 Ctrl+C 可中断并清理已搬移的部分
- [ ] 单文件搬移成功返回退出码 0
- [ ] Typecheck 通过

### US-003: 异步模式数据搬移
**描述：** 作为用户，我选择异步模式时，工具立即返回任务 ID，我可以通过任务 ID 查询搬移进度和最终结果。

**验收标准：**
- [ ] 异步模式下，提交任务后立即打印任务 ID 并退出
- [ ] 提供查询命令（如 `--status <task-id>`）查看搬移进度和状态
- [ ] 异步任务完成后，查询结果中包含搬移总大小、耗时、成功/失败状态
- [ ] 支持同时提交多个异步任务，互不干扰
- [ ] Typecheck 通过

### US-004: 大文件搬移优化
**描述：** 作为用户，当我搬移超过 1GB 的大文件时，工具不会耗尽内存或长时间无响应。

**验收标准：**
- [ ] 大文件搬移采用分块读写，不将整个文件加载到内存
- [ ] 搬移过程中内存占用保持稳定，不随文件大小线性增长
- [ ] 大文件搬移进度更新的粒度合理（>1GB 文件至少每 10% 或每秒更新一次）
- [ ] Typecheck 通过

## 功能需求

- FR-1: 工具必须支持 `--src <path>` 和 `--dst <path>` 命名参数
- FR-2: 工具必须支持 `--mode sync|async` 参数选择搬移模式，缺省为 sync
- FR-3: 工具必须支持 `--help` 显示完整帮助信息
- FR-4: 同步模式下，工具必须阻塞等待搬移完成并输出进度和结果
- FR-5: 异步模式下，工具必须立即返回唯一任务 ID 并退出
- FR-6: 工具必须支持 `--status <task-id>` 查询异步任务的状态和结果
- FR-7: 工具必须对大文件采用分块读写策略
- FR-8: 源路径不存在或目标路径不可写时，工具必须给出明确的错误信息
- FR-9: 搬移过程中用户可中断（Ctrl+C），工具应清理部分已搬移的数据

## 非目标

- 不支持跨网络/远程文件系统搬移（仅限本地文件系统）
- 不支持断点续传
- 不支持增量同步或差异同步
- 不提供 GUI 界面
- 不提供任务持久化（异步任务状态仅在进程存活期间有效）
- 不支持目录嵌套结构的完整保留（仅搬移单文件或平铺目录内容）

## 设计考虑

- 命令行界面风格参考 Unix 工具惯例，使用双横线长选项
- 进度信息输出到 stderr，结果信息输出到 stdout
- 工具退出码遵循惯例：0=成功，非0=失败

## 技术考虑

- 大文件搬移必须使用流式分块读写，避免全量加载到内存
- 异步模式的任务状态管理在进程内存中进行，不依赖外部存储
- 异步任务 ID 需保证单次运行内的唯一性
- 搬移过程中的中断信号（SIGINT/Ctrl+C）需注册处理函数
- 依赖：操作系统文件 I/O 系统调用、信号处理机制

## 成功指标

- 用户可以在一次命令行调用中完成数据搬移
- 同步模式下，大文件（>1GB）搬移内存占用不超过 64MB
- 异步模式下，任务提交后终端响应时间 < 100ms
- 用户可以在 2 分钟内学会基本使用方法（由 --help 引导）
