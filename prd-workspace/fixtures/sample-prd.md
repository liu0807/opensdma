# PRD: SDMA-DK 异步传输增强

## 简介
对 sdma-dk 库的异步传输能力进行增强，增加超时配置和回调通知功能，使上层应用能更灵活地控制异步操作。

## 目标
1. 支持异步传输超时配置（默认 5 秒）
2. 传输完成后通过回调通知调用方
3. 兼容现有同步传输接口

## 用户故事

### US-001: 异步超时配置
作为 sdma-dk 用户，我希望在发起异步传输时能配置超时时间，以便在硬件无响应时能够及时恢复。

验收标准：
- 新增 `sdma_async_timeout` 参数
- 超时取值范围 1-60 秒
- 超时触发时回调返回超时错误码
- 向后兼容：未配置时默认 5 秒

### US-002: 传输完成回调
作为 sdma-dk 用户，我希望在异步传输完成时收到回调通知，以便及时处理传输结果。

验收标准：
- 新增回调函数注册接口
- 回调携带传输状态和错误码
- 支持注册和注销回调
- 回调在独立线程中执行，不阻塞数据传输

### US-003: 异步批量传输
作为 sdma-dk 用户，我希望一次提交多个缓冲区的异步传输请求，以减少多次调用开销。

验收标准：
- 新增批量提交接口，支持最多 32 个缓冲区
- 批量提交返回唯一批次 ID
- 支持查询批次完成状态
- 与现有单缓冲异步接口共存

## 功能需求
FR-1: 超时配置接口
FR-2: 回调注册机制
FR-3: 批量提交接口
FR-4: 批量状态查询

## 非目标
- 不修改同步传输接口
- 不做跨平台兼容性改造
- 不引入新的外部依赖

## 技术考虑
- 使用 pthread 处理回调线程
- 超时通过 timerfd 实现
- 批量缓冲区采用 scatter-gather list 管理

## 成功指标
- 回调触发延迟 < 1ms
- 批量提交性能不低于逐次提交的 90%
- 超时测试 100 次无泄漏
