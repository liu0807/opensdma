增强版遗漏问题分析

增强版虽然发现了更深层的并发和架构问题（aarch64 弱序、非原子减），但遗漏了一些"表层"问题：

  • 线程 error-path use-after-free（HIGH）：pthread_create 后 goto 跳转，未 join 的线程访问已释放的栈内存。增强版主要关注了 D8 的同步原语类问题，但未检查 D8 检查清单中的第 8.10 项"线程间数据传递生命周期"。
  • request 零值初始化风险（MEDIUM）：D5.8 要求检查 request 在 iwait 时正确传递，但增强版未检查 sdma_request_t 零值是否被 API 接受。
  • 死代码检测（LOW）：增强版专注于高价值发现，自动过滤了低价值死代码问题。但在 strict 模式下这些也应该被报告。

迭代 3 改进方向

  1. 补充 D8 检查项 8.10（线程数据生命周期）：明确要求检查 pthread_create 后错误路径的线程泄漏和 use-after-free
  2. 补充 D5.8 增强：增加 sdma_request_t 零值/未初始化检测项
  3. 增加 D11 死代码检查项：D11.10 已提到死代码，需要强化对逻辑死代码（条件永远成立/不成立）的检测
